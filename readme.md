#Backend - Inventario de productos

API REST desarrolada con Django REST framework para gestionar un catálogo de productos (crear, consultar, actualizar y eliminar)

##Instalación 
1.Crear entorno virtual: python -m venv env
2.Activar entorno virtual
3.Instalar dependencias: pip install -r requirements. txt
4.Ejecutar migraciones: python manage.py migrate
5.Levantar al servidor: python manage.py runserver
